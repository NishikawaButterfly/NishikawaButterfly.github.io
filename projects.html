Projects

Seven public projects, each with a tagged release, tests, and invented sample data. Ordered roughly by how much there is to look at.

dc-twin

A deterministic, capacity-constrained simulator for synthetic data-center electrical architectures. You give it a versioned design snapshot and a scenario of failures, maintenance windows, and transfers; it returns a timeline of which loads stayed served, which paths carried the power, when each UPS ran down, and what caused every alarm. The same inputs and model version always reproduce the same SHA-256 result hash, so any run can be replayed and verified, and the reference scenario's numbers are hand-calculated with the expected values committed independently of the engine.

Python · FastAPI (read-only API) · plain JavaScript explorer · PostgreSQL · Docker Compose

Repository · v0.2.0 release with demo video · Live explorer

Electrical Asset Validator

A self-hosted web app for checking electrical asset registers before they move between design, commissioning, and operations teams. Upload a CSV or XLSX file and it validates a documented nine-column contract — duplicate tags, missing panel and circuit references, out-of-range voltage and power — with every finding tied to its row and field. It also diffs two revisions of the same register by stable asset tag, and results download as PDF or XLSX reports.

FastAPI · React + TypeScript · PostgreSQL · Docker Compose

Repository · Demo video (v0.1.0) · Live demo

Quant Risk Engine

A reproducible portfolio-analytics and market-risk engine for public securities, and deliberately not a prediction tool. Validated price series, the standard risk metrics with every convention documented, risk contributions that sum to one, an efficient frontier checked against its closed form, walk-forward backtesting where look-ahead is impossible by construction, seeded Monte Carlo, and stress windows and shocks. The CLI writes a committee-style report that is byte-identical across runs, and every worked example in the docs is hand-calculated and pinned by tests.

Python · NumPy and SciPy as the only runtime dependencies · CLI

Repository · Releases

Energy Investment Lab

A cash-flow and financing model for energy assets, in plain Python with no runtime dependencies. It handles escalated revenues and costs, annuity debt with DSCR, corporate tax with depreciation and loss carryforward, MIRR, levelized cost, one-at-a-time sensitivities, and a seeded Monte Carlo whose results are reproducible to the byte. One scenario file in; a results file and a committee-style report out, with every worked example in the docs hand-calculated and pinned by tests.

Plain Python, zero runtime dependencies · CLI

Repository · Releases

Critical Facilities Manager

An operations and commissioning platform for critical facilities, developed and tested privately and now public. Locations, assets, and maintenance orders with validated state machines; MOP/SOP/EOP procedures with four-eyes approval; work permits that block completing an order while one is still open; commissioning tests with witnessed evidence; and an append-only audit trail behind every write. Mutual-exclusion constraints stop simultaneous maintenance on redundant equipment: starting the second order is rejected with a 409 that names the constraint and the conflicting order.

Python · FastAPI · SQLAlchemy · bearer-token auth with roles · 237 tests

Repository · Releases

PV-BESS dispatch model

A Python model for dispatch of solar-plus-battery plants. It reads hourly PV production and market prices, computes a battery dispatch schedule as a mixed-integer program solved with HiGHS, and works out NPV, IRR, payback, and LCOS for the scenario. Rebuilt from an older prototype after an audit found calculation errors in the original, so it is deliberately small and heavily tested, with solver benchmarks published in the docs.

Python · SciPy MILP (HiGHS) · optional FastAPI API · dependency-free results page

Repository · Demo video (v0.1.0) · Live explorer

Sudoku Instant

A sudoku game as an installable progressive web app. Six difficulty levels, 24 puzzles each checked to have exactly one solution, candidate notes, hints, undo, full keyboard play, offline support, and locally saved progress. The first version was a single HTML file; some messaging apps opened it in a restricted preview where the JavaScript couldn't run, so it became a proper PWA.

Plain JavaScript, no framework · service worker · Playwright tests
