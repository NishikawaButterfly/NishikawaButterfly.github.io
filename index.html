Three places to start

dc-twin

A deterministic capacity simulator for data-center electrical architectures. Describe a topology and a scenario of failures and maintenance windows; it returns a timeline of which loads stayed served, when each UPS ran down, and what caused every alarm.

The interesting bit: the reference scenario's numbers are checked against a hand calculation, and the expected values are committed separately from the engine, so the tests notice if the code ever drifts from the math.

Live explorer · Repository

Electrical Asset Validator

A web app that checks CSV and XLSX electrical asset registers before they get handed between teams, and diffs two revisions of the same register by asset tag. Every finding names the row and field it refers to, and results export to PDF or XLSX.

The interesting bit: both file formats go through exactly the same rules, so the same register produces the same findings either way — and the diff reports a renamed tag as a removal plus an addition instead of guessing.

Live demo · Repository

Critical Facilities Manager

An operations and commissioning platform for critical facilities: maintenance orders with validated state machines, MOP/SOP/EOP procedures with four-eyes approval, work permits, commissioning evidence, and an append-only audit trail behind every write.

The interesting bit: mutual-exclusion constraints stop simultaneous maintenance on redundant equipment — starting the second order is rejected with a 409 that names the constraint and the conflicting order.
